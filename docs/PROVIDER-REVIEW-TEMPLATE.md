- Provider, endpoint, purpose, and data fields sent.

- Display, caching, redistribution, and attribution rights.
- Rate limits, pricing, SLA, and termination conditions.
- Submission visibility and whether user input becomes public.
- Subprocessor location, retention, deletion, and security contacts.
- Written provider confirmation when Terms are ambiguous.
